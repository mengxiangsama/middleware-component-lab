# Contributing

Thanks for helping improve Middleware Component Lab.

1. Fork the repository and create a focused branch.
2. For a component guide, explain what it solves, when to use it, how to connect it, and how to verify it. For a combination, describe each component's role, the data flow, the settings that connect them, and the observable result. Link the guide from the [catalog](docs/components/README.md) and the root README, cite upstream sources, and identify what you ran locally.
3. Run `./mvnw verify`.
4. Open a pull request describing the change and what you verified. For changes to runnable examples, update the relevant tests.

Please keep examples safe to run locally and never commit credentials or production endpoints.
