# Contributing

Thanks for helping improve Middleware Component Lab.

1. Fork the repository and create a focused branch.
2. For a component guide, update the [catalog](docs/components/README.md) with the component's common uses, setup steps, behavior limits, a local verification exercise, and upstream sources. Mark whether this repository includes a runnable example.
3. Run `./mvnw verify`.
4. Open a pull request describing the change and what you verified. For changes to runnable examples, update the relevant tests.

Please keep examples safe to run locally and never commit credentials or production endpoints.
